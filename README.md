# Kaimahi Homebrew Tap

Install the stable Kaimahi Agent Builder CLI:

```bash
brew install kaimahi-agents/tap/kmx
```

The fully qualified formula trusts only `kmx`, rather than every current and
future item in this tap. The formula installs Kaimahi's checksummed GitHub
release binaries for macOS and Linux on ARM and Intel.

Upgrade with:

```bash
brew upgrade kaimahi-agents/tap/kmx
```

Kaimahi is pre-1.0 and incubating. See the
[release and upgrade guide](https://github.com/kaimahi-agents/kaimahi/blob/main/docs/releases.md)
before upgrading across minor versions.
